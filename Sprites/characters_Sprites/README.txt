One folder per character. Inside each: frames/ (single PNGs, e.g. run_0.png), strips/ (one PNG per animation), info.txt.
Godot: make an AnimatedSprite2D, create SpriteFrames, and drag the frames (or use "Add frames from sprite sheet" on a strip).
Turn off texture filtering (Nearest) so the pixels stay sharp.

Characters: player, walker, flyer, turret, hopper, spikeball, shielder, bat, spider, slime, ghost, wheel, jetpack, mine, crab, mole, tank, fish, boss
